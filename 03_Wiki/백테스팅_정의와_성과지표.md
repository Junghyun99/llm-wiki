# 백테스팅_정의와_성과지표

백테스팅(Backtesting)이란 실제 자본을 투입하기 전에 과거 시장 데이터로 투자 전략의 유효성을 검증하는 과정이다. 퀀트 투자의 출발점이며, 전략의 기대 수익과 리스크를 정량적 근거로 평가할 수 있다는 점에서 감(感) 기반 투자와 구별된다.

## 4단계 절차

1. **투자 가설 수립** — 어떤 팩터 또는 패턴이 수익을 만드는지 명제화
2. **과거 데이터 수집** — 검증 대상 기간의 시세·재무·거시 데이터 확보
3. **전략 코드화** — 매수·매도 규칙을 알고리즘으로 구현
4. **성과 지표 분석** — 아래 지표로 전략 품질을 정량 평가

## 주요 성과 지표

| 지표 | 설명 |
|------|------|
| [[CAGR]] (연평균 복리 수익률) | 전략의 연환산 복리 성장률 |
| [[MDD_최대낙폭]] (Max Drawdown) | 고점 대비 최대 손실 폭 — 리스크의 핵심 척도 |
| [[샤프지수]] (Sharpe Ratio) | 단위 리스크당 초과 수익률 — 위험 조정 성과 비교 기준 |
| 승률 | 전체 거래 중 수익 거래 비율 |

## 실전 주의사항

- **거래비용 반영 필수:** 수수료·슬리피지를 빠뜨리면 실제보다 수익률이 크게 과장된다.
- **표본 크기:** 통계적 유의성을 확보하려면 최소 30회 이상의 거래 횟수가 필요하다.
- **시장 체제 변화:** 특정 환경(저금리·강세장)에서만 유효한 전략은 체제 전환 후 무력화된다.
