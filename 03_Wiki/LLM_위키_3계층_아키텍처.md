# LLM_위키_3계층_아키텍처

## 개요

LLM 기반 위키 시스템은 세 개의 명확히 분리된 계층으로 구성된다. 각 계층은 소유권과 변경 권한이 다르다.

## 3계층 구조

**1. Raw Sources (원본 소스)**
사용자가 수집한 문서들(논문, 기사, 이미지, 데이터 파일)이 저장되는 계층. **불변(Immutable)**이며 LLM은 읽기만 가능하고 수정할 수 없다. 시스템의 단일 진실 공급원(Source of Truth)이다.

**2. The Wiki (위키)**
LLM이 생성하고 유지보수하는 마크다운 파일들의 집합. 요약 페이지, 엔티티 페이지, 개념 페이지, 비교 문서, 종합 문서 등으로 구성된다. **LLM이 완전히 소유**하며 사람은 읽기만 한다. 새 소스가 추가되면 LLM이 관련 페이지를 업데이트하고 교차 참조를 유지한다.

**3. The Schema (스키마)**
`CLAUDE.md` 또는 `AGENTS.md`와 같이 LLM에게 위키 구조, 컨벤션, 워크플로우를 지시하는 설정 문서. 이 파일이 LLM을 일반 챗봇이 아닌 **규율 잡힌 위키 관리자**로 만드는 핵심이다. 사용자와 LLM이 함께 도메인에 맞게 점진적으로 발전시켜 나간다.
