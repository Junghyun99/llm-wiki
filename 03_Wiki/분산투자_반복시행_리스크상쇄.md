# 분산투자_반복시행_리스크상쇄

가치 투자나 자산 배분 같은 장기 투자에서 '반복 시행'은 시간축을 따라 여러 번 매매하는 것을 의미하지 않는다. 대신 같은 시점에 여러 종목이나 자산군에 나누어 투자함으로써, 공간적으로 반복 시행의 효과를 얻는다.

개별 기업은 언제든 예측 불가능한 돌발 악재(경영진 리스크, 소송, 회계 부정 등)로 실패할 확률을 갖는다. 하나의 종목에 집중하면 이 실패 확률이 그대로 전체 수익률에 반영되지만, 여러 종목으로 분산하면 개별 종목의 실패가 전체 포트폴리오에 미치는 영향이 상쇄되고, [[확률우위_반복시행_투자원칙]]에서 설명하는 확률적 우위가 누적되어 장기적으로 기댓값에 수렴할 가능성이 높아진다.
