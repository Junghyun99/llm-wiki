# 백테스팅_3대_편향

올바른 백테스팅 결과를 왜곡하는 구조적 편향 3가지. [[투자_리서치_3대_함정]]에서 개념적으로 다루는 과적합·생존편향을 백테스팅 실전 맥락에서 수치와 해결 기법 중심으로 재정리한 노트다.

## 1. 생존자 편향 (Survivorship Bias)

현재 시장에 생존한 종목만으로 과거를 테스트하면, 상장폐지·파산한 종목의 손실이 데이터에서 제거되어 **수익률이 연 1~4% 과대 추정**된다. 이 오차는 복리로 누적되어 장기 백테스트일수록 왜곡이 심해진다.

- **해결책:** 테스트 시점 기준 전체 유니버스(delisted 종목 포함)를 사용하는 Point-in-Time 데이터를 확보한다.

## 2. 미래 참조 편향 (Look-Ahead Bias)

백테스트 시점에 실제로는 알 수 없었을 미래 정보를 무의식적으로 사용하는 오류. 예: 당일 종가를 당일 매수 신호 판단에 사용하거나, 분기 실적 발표 전 데이터를 발표 후 기준으로 집계하는 경우.

- **해결책:** 신호 생성 시점과 체결 시점을 엄격히 분리하고, 재무 데이터는 공시 시점 기준으로 처리한다.

## 3. 과적합 (Overfitting)

과거 데이터에 파라미터를 반복 최적화하면 모델이 과거의 노이즈까지 학습하여 실전에서 무력화된다. 백테스트 결과가 지나치게 좋을수록 과적합을 의심해야 한다.

- **해결책:** [[백테스팅_검증_방법론]]의 Walk-Forward Analysis·Out-of-Sample 검증으로 일반화 성능을 확인하고 파라미터 수를 최소화한다.
