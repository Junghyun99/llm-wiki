# 세법상 가족관계 분류표

세법에서 사용하는 5가지 가족 범주와 해당 가족 예시는 다음과 같다.

| 구분 | 의미 | 해당 가족 (예시) |
|---|---|---|
| **배우자** | 혼인으로 결합된 동반자 (0촌) | 남편, 아내 |
| **직계존속** | 나를 낳아준 수직선 상의 윗사람 | 부모, 조부모, 외조부모, 증조부모 |
| **직계비속** | 내가 낳은 수직선 상의 아랫사람 | 자녀, 손자녀, 외손자녀, 증손자녀 |
| **방계혈족** | 같은 조상에서 옆으로 갈라진 핏줄 | 형제자매, 삼촌, 고모, 이모, 조카 |
| **인척** | 혼인을 통해 맺어진 관계 | 며느리, 사위, 장인·장모, 시부모, 처남, 형수 |

각 범주는 [[증여세_관계별_비과세_한도표]]에서 공제 한도를 달리 적용받는다. 배우자가 가장 높고(6억), 기타 친족(방계혈족·인척)이 가장 낮다(1,000만 원).
