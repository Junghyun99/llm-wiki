# 위키_인덱싱_및_로깅_전략

## 개요

위키가 커질수록 LLM이 관련 페이지를 빠르게 찾을 수 있도록 두 개의 특수 파일을 운영한다. 이 두 파일은 목적이 서로 다르며, 임베딩 기반 RAG 인프라 없이도 수백 개 페이지 규모까지 충분히 작동한다.

## index.md (콘텐츠 중심)

위키의 모든 페이지를 카탈로그화한 파일. 각 페이지의 링크, 한 줄 요약, 날짜·소스 수 등 메타데이터를 포함하며 카테고리(엔티티, 개념, 소스 등)별로 정리된다. LLM은 Ingest마다 이 파일을 업데이트한다. 쿼리 응답 시 LLM은 index.md를 먼저 읽어 관련 페이지를 파악한 후 상세 내용으로 드릴다운한다.

## log.md (시간 순서 중심)

Ingest, 쿼리, Lint 작업의 **추가만 가능한(Append-only)** 타임라인 기록. 각 항목을 일관된 접두사로 시작하면 Unix 도구로 파싱 가능하다.

```bash
# 최근 5개 항목 조회
grep "^## \[" log.md | tail -5
```

항목 형식 예시:
```
## [2026-05-22] ingest | Karpathy LLM Wiki 패턴
## [2026-05-22] query | RAG vs 영구 위키 차이점
## [2026-05-22] lint | 고아 노드 2건 구출
```

log.md는 위키의 진화 타임라인을 제공하며, LLM이 최근에 무엇을 했는지 파악하는 데 도움을 준다.
