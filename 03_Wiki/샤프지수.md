# 샤프지수

**샤프지수(Sharpe Ratio)**는 위험 1단위당 초과 수익률을 측정하는 **위험조정수익률 지표**다. 1966년 노벨 경제학상 수상자 윌리엄 샤프(William F. Sharpe)가 펀드 성과 비교를 위해 개발했다.

## 공식

$$
\text{Sharpe Ratio} = \frac{R_p - R_f}{\sigma_p}
$$

| 기호 | 의미 |
|------|------|
| $R_p$ | 포트폴리오(전략)의 평균 수익률 |
| $R_f$ | 무위험수익률 (국고채, CD금리 등) |
| $\sigma_p$ | 포트폴리오 초과 수익률의 표준편차 (변동성) |

## 해석 기준

| 샤프지수 범위 | 평가 |
|-------------|------|
| < 0 | 무위험 자산보다 못한 성과 |
| 0 ~ 1 | 보통 이하 (투자 고려 최저선) |
| 1 ~ 2 | 양호 (좋은 전략) |
| 2 ~ 3 | 우수 |
| > 3 | 매우 우수 (탁월한 전략) |

참고: S&P 500의 장기 연환산 샤프지수는 약 **0.4~0.5** 수준이다.

## 퀀트 트레이딩에서의 활용

- 서로 다른 전략을 **동일 기준으로 비교**할 때 핵심 척도로 사용
- 수익률이 같아도 변동성이 낮은 전략이 더 높은 샤프지수를 가짐
- 연환산 샤프지수 계산 시: 일별 샤프 × √252 (거래일 기준)

```python
import numpy as np

def sharpe_ratio(returns, risk_free_rate=0.0, periods_per_year=252):
    """
    returns: 일별 수익률 시리즈 (pandas Series)
    risk_free_rate: 연환산 무위험수익률 (기본값 0)
    """
    excess = returns - risk_free_rate / periods_per_year
    # 실전 사용 시 excess.std() == 0 또는 NaN 예외 처리 필요 (데이터 부족·수익률 완전 동일 케이스)
    return (excess.mean() / excess.std()) * np.sqrt(periods_per_year)
```

## 한계 및 주의사항

1. **정규분포 가정:** 수익률이 정규분포를 따르지 않으면 왜곡 (팻테일, 비대칭 전략)
2. **옵션 매도 전략 과대평가:** 꾸준히 소폭 수익 후 대폭 손실 구조는 높은 샤프지수에도 실제 위험이 큼
3. **음의 변동성 미구분:** 상방·하방 변동성을 구분하지 않음 → [[소르티노지수]]로 보완 가능
4. **측정 기간 의존:** 측정 주기(일·월·연)에 따라 결과가 달라짐
