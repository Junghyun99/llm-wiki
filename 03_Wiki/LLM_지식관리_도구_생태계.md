# LLM_지식관리_도구_생태계

## 개요

LLM 위키 시스템을 강화하는 주변 도구들의 생태계다. 모두 선택 사항이며 필요에 따라 조합해서 사용한다.

## 핵심 도구

**[[Obsidian]]** — 위키의 IDE. 그래프 뷰로 페이지 간 연결 구조를 시각화할 수 있고, [[Obsidian_Web_Clipper]]로 웹 기사를 마크다운으로 즉시 변환할 수 있다. 이미지는 로컬로 다운로드하는 것이 권장된다(URL 깨짐 방지).

**[[qmd]]** — 로컬 마크다운 검색 엔진. BM25/벡터 하이브리드 검색과 LLM 리랭킹을 온디바이스로 제공한다. CLI(LLM 셸 아웃용)와 MCP 서버(네이티브 도구용) 모두 지원한다. 위키가 커져서 index.md만으로 검색이 불충분해질 때 도입을 검토한다.

## Obsidian 플러그인

**[[Marp]]** — 마크다운 기반 슬라이드 덱 생성 플러그인. 위키 콘텐츠에서 직접 발표 자료를 생성할 수 있다.

**[[Dataview]]** — YAML 프론트매터를 쿼리하는 플러그인. LLM이 페이지에 태그, 날짜, 소스 수 등을 프론트매터로 추가하면 Dataview로 동적 테이블과 리스트를 생성할 수 있다.

## 인프라

위키 자체가 **git 저장소**이므로 버전 히스토리, 브랜칭, 협업 기능을 무료로 얻는다. 별도 데이터베이스나 벡터 스토어 없이도 수백 페이지 규모까지 운영 가능하다.
