# 소르티노지수

## 핵심 개념
소르티노 비율(Sortino Ratio)은 포트폴리오의 **하락 위험(Downside Risk)만을 기준으로 한 위험 조정 수익률 지표**다. [[샤프지수]]가 상승·하락 변동성을 모두 페널티로 부과하는 것과 달리, 소르티노 비율은 투자자에게 실제 손해를 주는 **하방 편차(Downside Deviation)만을 위험으로 간주**한다.

## 공식

$$
\text{Sortino Ratio} = \frac{R_p - R_f}{\sigma_d}
$$

| 기호 | 의미 |
|------|------|
| $R_p$ | 포트폴리오(전략) 수익률 |
| $R_f$ | 무위험 수익률 (예: 연 2% → 월 0.167%) |
| $\sigma_d$ | 하방 표준편차 (Downside Deviation) |

### 하방 표준편차 계산

$$
\sigma_d = \sqrt{\frac{1}{N} \sum_{i: R_i < R_f} (R_i - R_f)^2}
$$

- 기준값($R_f$) **미만**의 수익률만 제곱합산한 뒤 평균의 제곱근을 구한다.
- 기준값 이상인 수익률은 0으로 처리(페널티 없음).

## 샤프지수와의 차이

| 구분 | [[샤프지수]] (Sharpe Ratio) | 소르티노지수 |
|------|--------------------------|-------------|
| 위험 측정 기준 | 전체 표준편차 (상승 + 하락) | 하방 표준편차 (하락만) |
| 상승 변동성 처리 | 페널티 부과 | 무시 |
| 적합 상황 | 일반적 성과 비교 | 손실 최소화가 중요한 전략 비교 |
| 한계 | 수익 변동도 나쁜 위험으로 봄 | 좌측 비대칭 분포에서 더 정확 |

> 상승 추세가 강한 전략은 샤프 비율보다 소르티노 비율이 **더 높게** 나온다.

## 파이썬 구현

```python
import numpy as np
import pandas as pd

def sortino_ratio(returns: pd.Series, risk_free_rate: float = 0.02, periods: int = 252) -> float:
    """
    연간화된 소르티노 비율 계산
    
    Args:
        returns: 일별 수익률 시리즈
        risk_free_rate: 연간 무위험 수익률 (기본값 2%)
        periods: 연간화 기간 (일별=252, 월별=12)
    """
    daily_rf = risk_free_rate / periods
    excess_returns = returns - daily_rf
    
    # 하방 편차: 기준 미만 수익률만 추출
    downside_returns = excess_returns[excess_returns < 0]
    downside_std = np.sqrt(np.mean(downside_returns ** 2))
    
    annualized_excess = excess_returns.mean() * periods
    annualized_downside = downside_std * np.sqrt(periods)
    
    return annualized_excess / annualized_downside
```

## 해석 기준

| 소르티노 비율 | 평가 |
|--------------|------|
| < 0 | 위험 대비 수익 마이너스 |
| 0 ~ 1 | 보통 수준 |
| 1 ~ 2 | 양호 (실전 전략 기준선) |
| > 2 | 우수 |
| > 3 | 매우 우수 (장기 지속 어려움) |

## 한계 및 주의점
- 샘플 기간이 짧으면 하방 편차가 불안정해 신뢰도 낮음.
- 무위험 수익률 설정에 따라 값이 달라지므로 **동일 기준 비교** 필수.
- 수익률 분포가 정규분포를 따르지 않는 전략(옵션, 레버리지)에서는 보조 지표와 병행 사용 권장.
