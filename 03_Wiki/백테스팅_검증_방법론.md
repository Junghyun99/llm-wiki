# 백테스팅_검증_방법론

백테스팅의 [[백테스팅_3대_편향#3. 과적합 (Overfitting)|과적합]] 문제를 방지하고 전략의 실전 일반화 성능을 확인하기 위한 3가지 검증 기법. 단순 In-Sample 최적화에 그치지 않고 아래 방법론을 조합해야 신뢰할 수 있는 결과를 얻는다.

## 1. In-Sample / Out-of-Sample 분리

전체 데이터를 훈련용(In-Sample)과 검증용(Out-of-Sample)으로 나눠, 훈련용으로 최적화한 파라미터가 검증용에서도 유효한지 확인한다. 검증 데이터는 최적화 과정에 절대 노출되어선 안 된다.

- **일반적 비율:** 훈련 70% / 검증 30%, 또는 마지막 1~2년을 검증 구간으로 고정

## 2. Walk-Forward Analysis

시간 순서대로 롤링 윈도우를 이동하며 최적화→검증 사이클을 반복한다. 특정 시장 환경에만 맞춰진 파라미터가 다른 기간에도 작동하는지 확인하는 가장 현실적인 방법론이다.

```
[훈련1 | 검증1] → [훈련2 | 검증2] → [훈련3 | 검증3] → ...
```

각 검증 구간의 성과를 이어 붙인 최종 곡선이 전략의 실질 성과에 근사한다.

## 3. Monte Carlo Simulation

거래 순서를 무작위로 섞거나 수익률을 랜덤 샘플링하여 수천 가지 경로를 생성하고, MDD·CAGR의 분포를 분석한다. 단일 백테스트 결과에 의존하지 않고 **최악의 시나리오 확률**을 정량화할 수 있다.

- **활용 예:** "전략 MDD가 30%를 초과할 확률이 5% 이하인가?"를 시뮬레이션으로 검증
