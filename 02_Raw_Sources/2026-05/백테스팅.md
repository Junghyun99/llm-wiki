# 백테스팅

백테스팅이란 과거 시장 데이터를 사용하여 투자 전략이 실제로 유효한지 사전에 검증하는 과정이다. 퀀트 투자의 핵심 단계로, 전략의 수익성과 리스크를 정량적으로 평가할 수 있다.

## 핵심 개념

- **목적:** 실제 자본을 투입하기 전에 전략의 과거 성과를 평가하여 매매 결정의 근거를 마련한다.
- **과정:** ① 투자 가설 수립 → ② 과거 데이터 수집 → ③ 전략 코드화 → ④ 성과 지표 분석
- **주요 성과 지표:** CAGR(연평균 복리 수익률), MDD(최대 낙폭), 샤프 지수(Sharpe Ratio), 승률

## 3대 편향 함정 (Bias Traps)

올바른 백테스팅을 위해 반드시 피해야 할 편향이다.

### 1. 생존자 편향 (Survivorship Bias)
현재 거래되는 종목만으로 과거를 테스트할 경우, 상장폐지·파산한 종목의 손실이 제외되어 수익률이 **연 1~4% 과대 추정**된다. 해결책: 당시 존재했던 전체 종목 데이터(delisted 포함)를 사용한다.

### 2. 미래 참조 편향 (Look-Ahead Bias)
백테스트 시점에 실제로는 알 수 없었을 미래 정보를 무의식적으로 사용하는 오류다. 예: 당일 종가로 당일 매수 신호를 판단하는 경우. 해결책: 신호 생성 시점과 체결 시점을 엄격히 분리한다.

### 3. 과적합 (Overfitting)
과거 데이터에 파라미터를 과도하게 최적화하면 과거 노이즈까지 학습하여 실전에서 무력화된다. 해결책: Walk-Forward Analysis, Out-of-Sample 검증을 수행하고 파라미터 수를 최소화한다.

## 검증 방법론

| 방법 | 설명 |
|------|------|
| In-Sample / Out-of-Sample | 데이터를 훈련/검증용으로 분리하여 과적합 여부 확인 |
| Walk-Forward Analysis | 시간 순서대로 롤링 윈도우를 이동하며 반복 검증 |
| Monte Carlo Simulation | 무작위 샘플링으로 다양한 시나리오 분포 분석 |

## 실전 적용 시 주의사항

- **거래비용 반영 필수:** 수수료·슬리피지를 미반영하면 수익률이 실제보다 크게 과장된다.
- **시장 체제 변화 고려:** 특정 시장 환경(저금리, 강세장)에서만 유효한 전략은 실전에서 쉽게 무너진다.
- **표본 크기:** 통계적 유의성을 확보하려면 충분한 거래 횟수(일반적으로 30회 이상)가 필요하다.
