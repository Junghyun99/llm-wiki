# Description: #todo/fill 태그가 달린 스텁 노트를 웹 검색으로 초안 작성 후 사용자 승인을 받아 저장합니다.

## 실행 파이프라인 (Execution Pipeline)
너는 지금부터 `/fill-stubs` 명령을 수행한다. 외부 데이터를 위키에 통합하는 작업이므로 반드시 사용자 승인 후에만 파일을 저장한다.

1. **스텁 목록 확인:**
   `03_Wiki/` 내에서 `#todo/fill` 태그를 가진 파일을 grep으로 스캔한다.
   ```bash
   grep -rl "todo/fill" 03_Wiki/
   ```
   스텁이 없다면 "📭 처리할 스텁 노트가 없습니다."라고 출력하고 종료한다.

2. **스텁 목록 출력 및 선택 요청:**
   발견된 스텁 노트 목록을 사용자에게 보여주고 어떤 것을 채울지 선택을 요청한다.
   ```
   📭 미작성 스텁 노트 목록:
   1. `스텁노트1.md`
   2. `스텁노트2.md`
   3. `스텁노트3.md`

   채울 노트를 선택하세요. (번호 또는 "전체")
   ```

3. **웹 검색 및 초안 작성 (Loop):**
   선택된 각 스텁에 대해 다음을 반복한다.
   - 파일명에서 핵심 키워드를 추출하여 웹 검색을 수행한다.
   - 검색 결과를 종합하여 `extract-zettelkasten` 스킬의 영구 노트 양식에 맞는 초안을 작성한다.
   - 초안을 사용자에게 보여주고 승인을 요청한다.
   ```
   🔍 `스텁노트명.md` 초안

   [초안 내용 전체 출력]

   **참조 출처:**
   - 출처1 URL
   - 출처2 URL

   저장할까요? (승인 / 수정 요청 / 건너뛰기)
   ```
   - **승인:** 파일을 덮어쓰고 YAML의 `tags`에서 `todo/fill`을 제거한다.
   - **수정 요청:** 피드백을 반영하여 초안을 재작성하고 재승인을 요청한다.
   - **건너뛰기:** 해당 스텁을 그대로 두고 다음 스텁으로 넘어간다.

4. **index.md 및 log.md 업데이트:**
   저장된 노트가 1개 이상이면 아래를 갱신한다.
   - `index.md`: 해당 노트의 태그 컬럼에서 `todo/fill` 제거 및 요약 업데이트.
   - `log.md`: 맨 하단에 Append.
   ```
   ## [YYYY-MM-DD] fill-stubs | N개 스텁 보완
   - 완료: `노트명1.md`, `노트명2.md`
   - 건너뜀: `노트명3.md`
   ```

5. **결과 보고:**
   완료된 노트와 건너뛴 노트 목록을 요약 출력하고 종료한다.
