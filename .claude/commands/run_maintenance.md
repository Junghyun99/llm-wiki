# Description: 03_Wiki 내부를 스캔하여 중복 병합, 고립 노드 구출, 데드 링크를 복구합니다.

## 실행 파이프라인 (Execution Pipeline)
너는 지금부터 `/run-maintenance` 명령을 수행한다. 너에게 부여된 파일 읽기/쓰기 및 검색(grep) 도구를 활용하여 위키 전체를 최적화하라.

1. **위키 전수 조사:**
   `03_Wiki/` 디렉터리에 있는 모든 `.md` 파일의 목록과 내부 텍스트, 메타데이터(Frontmatter)를 메모리로 스캔한다.

2. **인지 및 판단 (Linting):**
   읽어들인 데이터를 바탕으로 `.claude/skills/lint-zettelkasten/SKILL.md`에 정의된 5대 유지보수 로직(A: 병합, B: 구출, C: 복구, D: MOC 최신화)을 적용해 '어떤 파일을 어떻게 바꿀지' 계획을 세운다.

3. **물리적 파일 조작 (Refactoring):**
   계획에 따라 파일을 덮어쓰거나(Edit), 지우거나(Delete), 새로 생성(Write)한다.
   - **[주의 사항]** 문서를 병합하여 파일명이 변경된 경우, 반드시 시스템 내의 다른 모든 파일에서 기존 이름을 가리키던 양방향 링크 텍스트(`[[기존_파일명]]`)를 찾아내어 새로운 이름으로 치환(Replace)해야 한다. (Bash의 `grep`과 `sed` 또는 파이썬 스크립트 도구를 적극 활용할 것).

4. **유지보수 리포트 출력:**
   모든 물리적 조작이 완료되면 `.claude/skills/lint-zettelkasten/SKILL.md` 파일 맨 하단에 명시된 '🧹 제텔카스텐 정비 리포트' 양식에 맞춰 최종 작업 결과를 터미널에 출력하고 작업을 종료한다.
